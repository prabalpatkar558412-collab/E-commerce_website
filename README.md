# 🛍️ ShopSphere – Full Stack E-Commerce Website

ShopSphere is a modern full-stack e-commerce platform built using the MERN Stack. It provides a premium shopping experience with user authentication, admin dashboard, product management, cart, wishlist, profile management, and secure backend APIs.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/shopsphere-ecommerce.git

cd shopsphere-ecommerce
```

---

### Backend Setup

```bash
cd server

npm install

npm run dev
```

Create `.env`

```env
PORT=5000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET_KEY

GOOGLE_CLIENT_ID=YOUR_GOOGLE_CLIENT_ID
```

---

### Frontend Setup

```bash
cd client

npm install

npm run dev
```

Create `.env`

```env
VITE_GOOGLE_CLIENT_ID=YOUR_GOOGLE_CLIENT_ID
```
